Pets novos

Três companheiros que seguem o jogador. Os sprites usam o mesmo quadro dos pets do jogo (22×31, de perfil, contorno de 1px) e são desenhados pixel a pixel a partir das grades abaixo.

No mapa

Cada jogador anda e para; o pet segue com a mesma lógica do pets.js.

Para colocar no jogo

  1. As linhas abaixo entram em assets/js/cosmetics.js, junto dos outros pets (logo depois de pet_holodog).
  2. Os frames seguem o formato de drawPet: quadro 22×31 virado para a direita (a esquerda é espelhada), chão na linha 28. O botão Grade de cada card copia a paleta e os frames em JSON.
  3. Os idles têm 4 frames; o pets.js hoje faz % 2 no idle e precisa passar a usar % s.idle.length.
  4. O morcego se pendurar no rack e os três efeitos são código novo no pets.js; esta página mostra como eles devem se comportar.
